# Virtualization and Cloud

## Within the Physical Server
**Virtual Machine** - A server that is split up to host different applications

**Containers** - Splits VM to maximize efficieny if same app is in use

**Hypervisor** - Acts as the supervisor between virtual machines

## Cloud
Servers accessed over the internet, and the software and databases that run on those servers.

Public - for websites/startups | Private - Governments and banks | Hybrid - Online Marketplaces

## IaaS vs PaaS vs SaaS
**IaaS** - You manage the VM and application, they manage physical server

**PaaS** - You manage the application, they do everything else

**SaaS** - Everything is done for you (using a software)
