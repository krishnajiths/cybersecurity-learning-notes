# Linux

## Interfaces
- **GUI:** Graphical User Interface
- **CLI:** Command Line Interface
- **Shell:** Facilitator between User and OS

## Shells 
- **Bash:** Default shell for most linux distributions. Borrows capabilities from older shells and combines them with its own unique abilities. 
- **Fish:** User Friendly Shell, it has very simple syntax combined with unique colors that allow for easy detection of errors. It also auto corrects spelling.
- **Zsh:** Z Shell, it is an advanced shell. This shell has the an excellent level of scripting. It combines abilities from the other 2 shells. Can be slower than other shells.
