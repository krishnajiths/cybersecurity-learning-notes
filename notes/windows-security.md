# Windows Security

# Services
- **Volume Shadow Copy Service (VSS):** coordinates the required actions to create a consistent shadow copy (also known as a snapshot or a point-in-time copy) of the data that is to be backed up. 
	Disabled by ransomeware to make sure no files are recovered

# Infrastructure
- **OU:** Organizational Unit (OU) refers to containers that hold users, groups and computers to which similar policies should apply.
- **Windows domain:** group of users and devices regulated by one administrator
- **Active Directory:** centralize the administration of common components of a Windows computer network in a single repository
- **Domain Controller:** The server that runs the Active Directory services
- **Security Groups** grants permission over resources

# Network & Enterprise Security
- **WAF:** Web Application Firewall, firewall that protects applications by filtering out HTTP/S requests
- **SIEM:** Security Information and Event Management (SIEM) is a cybersecurity solution that centralizes log data from an organization’s IT infrastructure, analyzing it in real-time to detect threats
- **NIDS (Network IDS):** “Passive Observer." It sits on the network wire and "Listens" for signs of trouble, like a security guard watching a monitor from a central office.
